# Vashawn Leonardi — Portfolio Website

A responsive, text-first portfolio built with plain HTML, CSS, and JavaScript. No framework or build step is required. The visual style is intentionally more editorial and understated, and the project areas are reserved for your own gameplay videos rather than fabricated illustrations.

## Files
- `index.html` — page content and video file paths
- `styles.css` — layout, typography, colours, and responsive design
- `script.js` — mobile navigation, video fallback handling, and copyright year
- `favicon.svg` — browser tab icon
- `videos/README.md` — instructions for adding gameplay videos

## Before publishing
1. Add your real GitHub profile link and project repository/demo links. The project link areas currently explain where those links can go; replace them with real links when available.
2. Verify project dates, the official competition name, OSN-P stage, and all descriptions.
3. Test the site on desktop and mobile, and make sure both videos play after deployment.
4. Your email is public on the website; that is normal for a portfolio, but it can attract spam.

## Recommended free hosting: GitHub Pages
1. Sign in or create an account at https://github.com.
2. Create a **public** repository named exactly `YOUR-GITHUB-USERNAME.github.io` (replace the placeholder with your actual GitHub username).
3. Upload the contents of this folder to the repository root. `index.html` must be at the root, not inside another folder.
4. Open **Settings → Pages** in the repository.
5. Under build/deployment source, select **Deploy from a branch**, then choose `main` and `/(root)` and save, if prompted.
6. Wait for deployment. The address will be `https://YOUR-GITHUB-USERNAME.github.io`.
7. When you commit and push future changes, Pages republishes the site.

Official guide: https://docs.github.com/en/pages/getting-started-with-github-pages
